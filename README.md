# 🍽️ LocalBites

> **Vote for the Dish, Not the Joint**

LocalBites is a modern food discovery web application that helps users find the best dishes in their neighborhood through community voting. Instead of rating entire restaurants, users can upvote or downvote individual dishes, discover trending meals, and share their own hidden gems.

---

## ✨ Features

- 🗺️ Interactive map view
- 👍 Upvote and 👎 downvote system
- 🔍 Search dishes and restaurants
- 🏷️ Filter by flavor tags
- 🏆 Top 5 local leaderboard
- ➕ Submit new dishes
- 📱 Fully responsive design
- 💾 Local Storage support
- 🔥 Trending and New badges
- 😊 Vibe rating system

## 🎯 How It Works

### Browse Dishes
Users can explore trending dishes and hidden gems in the area.

### Vote
Each dish can receive:
- 👍 Upvote
- 👎 Downvote

The leaderboard updates automatically.

### Search & Filter
Find dishes using:
- Restaurant name
- Dish name
- Flavor tags

### Submit a Bite
Users can contribute by adding:
- Restaurant name
- Dish name
- Price
- Distance
- Flavor tags
- Review
- Vibe rating
